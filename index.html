// About me

Short story on how I got here

My name is Jarosław Pokropiński. I am a software developer working mainly in full-stack web development, with focus on React apps. My journey with programming began with C and C++ which were my primary programming languages for a few years.

In university I started diversifying my knowledge learning many languages at various levels. I also started focusing on projects in web technologies (HTML, CSS, JavaScript, Typescript, NodeJs, Electron, React, Angular, Vue).

My commercial experience is in the field of fullstack web development with technologies such as React (with Typescript, CRA, Vite, NextJs, Redux Toolkit), Java (SpringBoot), and C++.

In my own time I code exploring topics I find interesing at the moment or create tools for my own enjoyment (lots of web only or Electron apps that are easy to deploy). I also maintain a simple home lab setup (Proxmox, Docker, ...) for family photos, home assistant, game servers, etc.
